African Foods Company – Static Website
A static website built for the African Foods Company (Scenario Two) as part of the Work Integrated Learning (WIL) group project, Task 2. The site is made with plain HTML and CSS only, with no frameworks or back end.

About the Project
African Foods Company operates from four sites: the Cape Town head office, Durban, Gqeberha and Polokwane. This website presents the company to the public and includes an internal IT SOP portal that documents the company's standard operating procedures.

Task 2 of the project covers:
-Standard Operating Procedures (SOPs)
-Disaster recovery (DR) plans
-A static website (this repository)

Pages
Page  | File |	Description
Home | index.html | Landing page with a navigation bar, a grey video hero section, yellow tiles and a footer.
Our Story |	about_us.html |	Company story with a picture, plus three columns for map, location and operating hours.
IT SOP Portal | SOPs.html |	Portal landing page with a right-hand "Pages" sidebar, a welcome/search box and 3x2 SOP category cards.
SOP category pages | (one per category) | IT structure, Security, Acceptable use, Acquisition, Service desk and Recovery.

Design
All pages share a single stylesheet, style.css, and follow the group's own wireframes:
-Colours: green navigation bar and footer, dark/grey content bands, yellow tiles
-Layout: simple, uncomplicated HTML and CSS
-Icons: green rounded icon tiles on the Our Story page
-SOP portal: green top bar, with the Pages sidebar on the right

How to Run
(No installation or build step is needed.)
1.Download the project folder.
2.Open index.html in any modern web browser (Chrome, Edge, Firefox or Safari).
3.Use the navigation bar to move between pages.
