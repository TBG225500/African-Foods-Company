Security policy

Passwords, data and incident handling.

Purpose

The purpose of these guidelines is to protect the organisation’s information, systems, networks, and IT equipment from security threats. Bidgoli (2021) stated that these guidelines will provide employees with clear instructions on how to safely use IT resources, protect confidential information, prevent unauthorised access and report security incidents. By following these guidelines, security risks will be reduced, and a safe and reliable environment will be maintained.

Guidelines

  • Access Controls: Biometrics, access cards and facial recognition is a crucial security control for protecting the network infrastructure of African Foods Company. They prevent unauthorised access to restricted areas.
  • Unified Threat Management (UTM): Security threats should be monitored and managed using integrated security measures. The UTM is an integration of multiple security functions such as firewalls, IDS/IPS, antivirus and content filtering.
  • AAA (Authentication, Authorisation, Accounting): Users must be authenticated (verify their identities). Users must be authorised (granted permission on what they can access). Accounting tracks user activity.
  • Passwords: Use strong passwords (containing uppercase and lowercase letters, numbers and symbols) allocated by the IT manager and keep them confidential
  • Data encryption: Sensitive information should be encrypted to prevent unauthorized access.
  • Software Updates: Operating systems and apps should be updated regularly in order to identify and fix security vulnerabilities.
  • Malware Protection: Antivirus software should be installed and updated regularly on all devices to protect them from malicious software/attacks
  • Zero trust security: Every user and device should be verified before being granted access to the system or network, no matter their location.
  • Backup and recovery: Important organisational data should be backed up regularly and restored when necessary.
